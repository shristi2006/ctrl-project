# 🎯 CTRL - Time Tracker Web App  

## 📝 Overview  
CTRL is a web application designed to help users track and optimize their daily activities to enhance focus and productivity.  

## 🚀 Features  
- 🔐 **User Authentication** - Supports Email/Password & Google Login  
- 📅 **144-Block Time Tracker** - Track daily activities in 10-minute slots  
- 📊 **Daily & Weekly Analysis Graphs** - Visual representation of time usage  
- ⏳ **Cold Turkey Mode** - Full-screen focus timer that blocks distractions  
- ✅ **To-Do List & Notes** - Keep track of tasks and thoughts  
- 🎨 **Responsive Design** - Optimized for all devices  

## 🛠️ Technology Stack  
- **HTML5** - Structuring web pages  
- **CSS3** - Styling and layout  
- **JavaScript (ES6+)** - Interactivity  
- **Firebase** - Authentication and data storage  
- **Chart.js** - Analytics and time tracking visualization
